Minimum viable second brain

Obsidian remembers everything you've learned.
Your AI agents don't.

knowledge-engine indexes your Obsidian vault into a local vector store, so any agent can retrieve what you've actually written, on demand, instead of relying on AGENTS.md you update by hand.

$ npm run query

At the moment, the only way to install is to clone the repository:

$ git clone https://github.com/sodrooome/knowledge-engine
$ cd knowledge-engine
$ npm install && npm run build

The gap

One brain, two memories

Every insight goes into Obsidian first. Nothing reaches your agents unless you copy it there by hand.

Without knowledge-engine

  • A gotcha you wrote down last week is invisible to your agent today
  • Memory files grow by manual onboarding, one paste at a time
  • Every agent keeps its own partial, stale copy of what you know

With knowledge-engine

  • Any note becomes retrievable the moment it's saved to the vault
  • Obsidian stays the single source of truth: nothing is duplicated
  • Research, writing, and engineering agents query the same index

Quick start

Point it at your vault

Indexing replaces each note's chunks on re-run, so edits propagate cleanly.

# not on npm: clone the repo, then install & build
git clone https://github.com/sodrooome/knowledge-engine
cd knowledge-engine
npm install
npm run build
# configure once: set EMBEDDING_API_KEY and LANCEDB_PATH in .env
cp .env.example .env
# index a vault (skips .obsidian, .trash)
npm run index -- ~/path/to/vault
# ask it something
npm run query -- "what do I know about eventual consistency?" 5
