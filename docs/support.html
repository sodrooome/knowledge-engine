Support

Free and open source. Honestly not free to run.

knowledge-engine is MIT-licensed and charges nothing, ever. There are two ways to help: build it with us, or fund the parts that cost real money.

Contribute

Code, tests, docs and bug reports all count. Start with CONTRIBUTING.md in the repo; it covers setup, ground rules and PR style.

Code

Bug fixes and roadmap features from planning.md: incremental indexer, file watcher, agent integration.

Tests

A hand-written repro test for a bug you found is worth more than any suite expansion.

Docs

README clarity, docstrings, examples, these pages. If something confused you, fixing it helps everyone after you.

Bug reports

Steps to reproduce, expected vs actual, your platform. Intel Mac users: include your LanceDB version.

The honest part about money

  • You never pay us. There is no paid tier, no license key, no feature behind a donation wall. Free means free.
  • Embeddings are billed by third parties, not by us. The default model (google/gemini-embedding-001) costs about $0.15 per million tokens through OpenRouter. Indexing a personal vault is typically well under a dollar, once, and each query costs fractions of a cent. You subscribe to them directly; we never see that money.
  • Zero-cost is possible today. Point EMBEDDING_BASE_URL at any OpenAI-compatible endpoint you host yourself (LM Studio, Ollama's server, infinity) and your embedding bill is exactly zero. Paid providers are convenience, not requirement.

Fund development

That said, this project isn't free to build: embedding bills for demos and testing, hardware to keep local models honest, and the hours that go into every reviewed change. If the tool saves you time, a small contribution keeps it moving.

Every bit goes to project costs and development time. No ads, no telemetry, no data collection; funding is the only revenue this project will ever have.
