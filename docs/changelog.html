Release history

Every notable change, newest first. Mirrors CHANGELOG.md in the repo; versions are semantic-ish: breaking changes to stored data bump the minor.

v0.1.1 2026-08-27

Opencode integration, search-only: the retriever is now available to agents as a first-class MCP tool.

Added

  • Opencode MCP server: src/mcp-server.ts exposing search_vault(query, k) — embeds with the asymmetric query task, runs cosine top-K (default 5, max 20), and returns ranked citations with the full chunk text so agents can ground answers in your notes
  • Lazy cached RAG runtime: the embedding dimension probe and LanceDB table open happen once per server process, not per query
  • Project-scoped MCP registration: the knowledge-engine server registered in opencode.json; setup documented for both project and global scope in the README
  • Demo screencast: assets/demo-screencast.mp4 embedded in the README and the docs Opencode page
  • Docs site deployment: a GitHub Pages workflow assembles docs/ and assets/ into a static site and deploys it to Pages
  • Dedicated Opencode guide: docs/opencode.html covering clone-based setup and MCP registration

Planned

  • Incremental indexing: skip unchanged notes on re-run; the bulk indexer is the skeleton
  • File watcher: re-index notes as they change in the vault
  • Indexing through MCP: expose an index_vault tool so agents can keep the index fresh
  • Native Gemini embedding adapter: fallback if OpenRouter's OpenAI-shaped surface disappoints on retrieval quality (RETRIEVAL_DOCUMENT vs RETRIEVAL_QUERY)
v0.1.0 2026-08-23

First coherent milestone: markdown vault in, cited semantic answers out, end to end via two CLIs.

Added

  • Heading-aware markdown parser: ATX headings up to 6 levels, fenced-code aware, frontmatter stripped, preamble sections supported
  • Section chunker: configurable size and overlap; stable chunk ids from content hashes
  • OpenAI-compatible embedding provider: OpenRouter's /api/v1/embeddings; one key covers chat and embeddings; default model google/gemini-embedding-001 at 3072 dimensions
  • LanceDB vector store: cosine top-K search, batched appends, deleteByDocument for idempotent re-indexing; one table per embedding model so switching models is non-destructive
  • Bulk indexer CLI: npm run index -- <vaultPath>; skips dotfolders; re-runs replace each note's chunks so edits propagate cleanly
  • Query CLI: npm run query -- "<question>" [k]; prints citations with distance, path, heading and lines
  • Shared RAG bootstrap wiring: config → provider → store, used by both CLIs and the smoke harness
  • End-to-end smoke harness: embed sample texts, store, run a semantic query
  • Fail-fast env configuration: EMBEDDING_API_KEY and LANCEDB_PATH validated at startup

Fixed

  • Pinned @lancedb/lancedb to 0.22.3, the last release shipping a native binary for Intel macOS (darwin-x64)

Project

  • Initial commit on 2026-07-14: project setup, parser, chunker, utils, manual tests

The core concept and architecture were designed by the author, with implementation assisted by Opencode. Every line of code is carefully reviewed by hand, and all tests are written manually.
